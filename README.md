# MemePlan（表情包管理工具）

## 项目简介

目前，我的微信收藏表情包数量已经超过 300 个，每次查找和使用都很困难。绿泡泡和企鹅之间的表情包数据也无法互通，于是 MemePlan 诞生了。

MemePlan 是一款 Android 表情包管理工具，可以从相册导入表情包，并为表情包添加标签、分类和收藏，帮助你更快地找到表情包。
同时，MemePlan支持快捷发送，虽然不如从社交软件直接发出那么方便= =

当前仅支持从相册导入，暂不支持直接从社交软件一键导入表情包（基于某公司的尿性，做了怕被发绿尸涵）

> 当前仅支持 Android11。

## 下载与安装

前往项目的 [Releases](https://github.com/Minoray308/MemePlan/releases) 页面，选择最新版本的 APK 下载并安装即可。

安装新版本时，如果 Android 提示“软件包与现有软件包冲突”，请先卸载旧版本再安装新版本。卸载会清除应用数据，请提前做好备份。

## 快捷发送

### 使用方法

1. 在主菜单中选择“悬浮按钮”。
2. 根据需要选择显示在悬浮窗中的标签或分类（可在设置中自定义）
3. 找到要发送的表情包并点击。
4. 在社交软件聊天框右侧点击“+”。
5. 点击弹出的表情包即可发送。
6. 发送完成后，点击悬浮窗中的“已发送”。

### 工作原理

部分社交软件在相册出现新图片后，点击聊天框旁的“+”会自动询问是否发送该图片。

想发某个表情包时，MemePlan先将表情包临时保存到相册，再利用社交软件的特性使用户完成快捷发送；发送完成后，MemePlan 会删除此临时资源。
